# 游戏内资源压缩与解压系统

## 项目描述

游戏内资源压缩与解压系统的bug修复项目。核心模块 `compression/compressor.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 压缩只用简单RLE压缩率极低
- 解压没有校验解压后文件损坏也不知道
- 字典编码完全没做重复数据不能有效压缩
- 校验和完全没做解压后文件损坏也不知道
- 流式处理完全没做必须全部下载完才能解压

## 运行测试

```bash
python -m pytest tests/test_compressor.py -q
```
